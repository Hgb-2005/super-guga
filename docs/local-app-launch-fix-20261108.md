# 本地微信与浏览器启动修复（2026-11-08）

## 本次问题与修复

实际会话中的“嗯，打开微信”“你现在重新打开微信”“先不打开微信了，打开豆包浏览器”没有匹配本地快速指令。语音端口头承诺执行，但没有相应启动回执；不能把这当作启动成功。

- 仅清理句首独立语气词和启动指令前的“现在／重新／再”。明确的“先不打开 A 了，打开 B”只启动 B。否定句、引用和说明性问句仍不启动软件。
- 默认浏览器启动沿用 Windows 注册的完整参数。豆包所需的 `--single-argument` 以前在通用“打开浏览器”路径中被遗漏。
- 豆包聊天窗口与浏览器共用 `Doubao.exe`。指定“豆包浏览器”时，在进程身份匹配之后筛选浏览器窗口，避免把聊天窗口也列为候选、因多窗口而直接停止。
- 更新运行版本标记为 `2026-11-08.app-launch.2`，便于确认当前进程已加载修复。

没有修改模型、凭据、免费额度设置或 Windows 权限。原有修改保留；修复前文件在 `runtime/upgrades/local-app-launch-fix-20261108-175957/`。独立工作区内的 DSH 融合暂缓，没有推送或创建 PR。
