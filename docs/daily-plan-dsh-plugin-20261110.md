# 每日计划与 DSH 咕嘎插件（2026-11-10）

## 怎么用

咕嘎聊天窗顶部、右键菜单和托盘均有「每日计划」。聊天里直接输入：

```text
设置每日计划：学习；运动；整理工作
每日计划 完成 学习
每日计划 取消勾选 学习
每日计划 把 学习 改成 阅读
每日计划 删除 整理工作
查看每日计划
查看打卡记录
```

设置清单会添加新事项，已有事项和勾选保留。删除需要明确写出；不会因重写一份清单而清空原计划。
窗口可逐项勾选、添加、改名、选定每周重复日期；默认每天重复。每日勾选独立，跨天自动从未完成开始。
历史按当时的名称和重复日期保存；删除重复计划不删除往日记录。记录位于 `runtime/chat/daily-plan.sqlite3`。

碎碎念开启后，每隔至少十分钟可穿插一次当日进度与鼓励；不打断正在说话、播音或前台回答。
非通话状态的清单鼓励本地生成，不调用聊天模型；声音复用现有 TTS 播放链。通话状态把真实勾选交给语音层表达。
勾选只表示用户在清单中确认完成；不会从聊天猜测、自动完成实际工作。

## DSH 作为宿主，咕嘎作为插件

现已升级为原生插件 `dsh-guga-desktop`，在本地 UI 的插件列表显示“咕嘎 · 桌面助手”。
它使用 DSH 现有的官方 MCP 客户端与工具注册接口，并订阅真实 `session/event`；没有下载其他组件。
本机已通过 `dsh plugin --profile web link` 链接项目内的插件，原配置已备份，旧的重复 MCP 配置已移除。

DSH 可调用 `mcp__guga__daily_plan`、`mcp__guga__computer`、`mcp__guga__wechat`、`mcp__guga__pet_say` 等接口。
桌面观察/输入仍受咕嘎自己的完整访问设置控制。气泡工具不调用模型、不发声、不写入聊天历史。
与咕嘎自身向 DSH 交接任务的 sidecar 分开：这里是独立 DSH 调用正在运行的咕嘎。

先启动咕嘎，再使用电脑原来的 DeepSeek Harness 图标。项目根目录 `体验DSH咕嘎插件.cmd` 也改为打开同一个本地 UI，保留 DSH 原模型。
首次加载新代码需要重启咕嘎和本地 DSH。不会默认另开网页服务或把咕嘎模型覆盖到 DSH。
独立 DSH 的 user/message、turn/start、step/start、tool/call、tool/result、公开答复与 turn/end 会回传给咕嘎；内部思考不转发。
咕嘎按会话区分任务，约30秒汇报一次；语音开启时使用现有通话播报，否则使用气泡和现有TTS。
聊天可输入“查看DSH进度”或“关注DSH会话 实际编号”。关注依据为最近发起任务的主会话，不自动跟随无新消息的UI页签切换。
外部 DSH 的暂停、取消和恢复仍在 DSH 内执行；当前没有从咕嘎反向控制其会话生命周期。

可体验的指令：

```text
通过咕嘎插件查看我的每日计划，把今天已勾选的事项告诉我，再让咕嘎显示一句鼓励。
```
