# 全新长对话与离线兜底（2026-11-07 晚）

## 用户实测反馈

打开浏览器、打开微信都失败；连"退下"也退不了；说"打开微信，找到小军"做不到，
还会翻出之前对话里的错误。用户明确要求：**每开一次长对话就是一个全新上下文**，
只保留本次对话内容和真正的系统提示词；人设为"傲娇毒舌但听主人话，会记住主人兴趣
爱好、最近在忙的事和背景"。

## 定位结果

### 1. 远程大脑当时是断的

实测 `https://opencode.ai/inference/go/openai/v1/chat/completions` 直接 SSL 握手失败，
本地兜底代理 `127.0.0.1:8477` 与 `8471` 也都没在监听。
任务日志 `runtime/agent-tasks/19536468302c4bdc8806d548af15a10e.json` 记录
`read_timeout / opencode.ai / 4172ms / operations=0`，与实测一致。

任何没被本地快速命令认出来的句子都会被送去这个大脑，于是表现为"什么都不做"。

### 2. 常用口语没被本地认出来

`match()` 只认"打开微信"这类顺序句。"把微信打开""微信打开一下""把浏览器打开"都不命中，
全部落到会超时的远程大脑。快速命令诊断文件仍停在 16:54，说明本地通道根本没跑。

### 3. 快速命令失败后还会自动转交同一个断线大脑

`_finish_fast_command` 原本在 open_app 失败时自动把原话重新发给 DeepSeek。
这既卡住当前回合，又把"失败详情"写进对话记录，成为下一轮对话的素材。

### 4. 每次新长对话都把旧对话整包搬进来

三处注入叠加：
- 开长对话时把聊天窗口最近 40 条消息塞进 `context_history`；
- `recall()` 把最近 40 条原始对话（含报错、播报、失败诊断）当"记忆"返回，
  并按当前问句做关键词加权，旧错误很容易排到最前；
- 后台任务状态、浏览器事实、上次快速命令失败记录也跨会话残留，被拼进系统指令。

系统提示词里还有"不能把未就绪当成没有屏幕能力"这类措辞，进一步鼓励模型翻旧账。

### 5. "退不了"

告别语用本地 TTS 播报，`_finish_voice_farewell` 会等它播完，最长等 12 秒；
若 TTS 卡住或循环，通话就一直不结束。第二次说"退下"也只是回一句"本鹅正在退下"，不动作。

## 修复

1. **本地匹配扩到倒装句**："把 X 打开""X 打开一下"等直接本地执行，不碰大脑。
2. **复合指令先做能做的**："打开微信，找到小军" 现在会先把微信打开，再明确说明
   后半句需要联网、当前没连上，不会假装完成，也不会整句卡死。
3. **删掉失败自动转交**：快速命令失败就报真实原因，不再把同一句话扔给断线的大脑，
   也不再把失败写进对话历史。
4. **新对话真干净**：`context_history=[]`；`recall()` 默认不再返回原始聊天记录；
   长期记忆只取明确的 `profile:*` / `user_preference`；后台任务、浏览器事实、
   上次失败记录开新通话时全部清空。
5. **人设改成主人给的规格**：傲娇、毒舌、听主人话、记住兴趣与近况，明确写了
   "每次长对话都是全新的开始""不翻旧账""把报错和诊断排除在主人画像之外"。
6. **退下立刻生效**：告别语不再阻塞结束流程，600 毫秒内退出；第二次催促直接结束通话。

## 验证

- 126 项回归全通过，含新增 `tools/test_fresh_context.py`（6 项）：
  人设、空上下文、旧错误不会被学成记忆、只保留明确的主人画像。
- 口语命中实测："把浏览器打开""浏览器打开""把微信打开""微信打开一下"全部本地命中；
  "打开微信，找到小军" 命中 open_app 并保留后半句；"打开百度"仍是网址，"关闭浏览器"
  仍走原有浏览器关闭路由，无误伤。

## 模型切换（主人指定）

主人指定大脑改用千问 3.8 Flash。实测确认：
- `qwen3.8-flash` 在 `https://dashscope.aliyuncs.com/compatible-mode/v1` 可用，同一个
  `sk-ws-` 千问 key 直接通用，不需要另配密钥，也不需要额外开通。
- 千问平台自己的 `maas.qianwenaiapi.com/api/v1/chat/completions` 返回 404（该域名只提供
  实时语音 WebSocket 与模型列表）；`cmaas-qwen3.8-flash` 返回 403，均不可用。
- 项目真实请求参数（流式、`thinking`、`stream_options`、四档思考强度）全部兼容，
  首包约 500-950ms，无需改代码。

`ai_config.json` 已切换：`base_url` → dashscope 兼容端点，`model` → `qwen3.8-flash`，
`api_key` → 复用千问实时语音的同一把 key。其他配置（智谱视觉、豆包 TTS、实时语音）原样保留。
备份：`ai_config.json.bak_before_qwen38_20261107`。

## 边界

复杂指令的后半段、需要推理的问答、网页内多步操作仍走远程大脑。现在大脑已恢复，
但本地能做的部分不会再被它拖住：常用口语与窗口操作始终本地直连，
复合句先把能做的那一步做完再明确说明剩下没做，不会假装完成。
