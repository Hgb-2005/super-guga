# 你说一步，咕嘎做一步：第一阶段

2026-11-08。目标是先把简单电脑操作做快、做准；复杂任务仍交给 DSH。

## 现在可以怎么用

开启长语音，把要操作的软件留在前台，逐句说：

- “点击搜索框。”
- “输入你好。”（替换当前输入框内容）
- “追加输入，今天有空吗？”（保留原文再追加）
- “在搜索框里输入你好。”
- “点击保存按钮。”
- “列出可点选项。”然后按刚显示的编号说“点击第2项”。
- “按回车。”“按Tab。”“按Esc。”“按Ctrl+f。”“向下滚动。”
- “停止当前操作。”（阻止尚未发出的操作；已经发生的操作不能自动撤回）

每句话只做这一步。成功后用气泡提示，继续听，不再追加一段确认语音。
普通的“取消”仍保留原来的任务处理含义，不擅自解释成按Esc。
不要把多个步骤连在一句话里；要输入的文字本身含操作指令时，可以加引号。

## 这次做了什么

原先仅适用于浏览器的快速操作，现在也接到了普通桌面软件。
能直接读到按钮和输入框时，优先按名称操作；确实读不到按钮时，再看一张当前窗口的图片定位。
看图只负责找你指定的目标，不负责安排后续步骤。图片只在内存中处理，必要时发给原有看图服务。

编号只属于当时的窗口，30秒后、操作后、通话重新开始后会失效。
按编号操作前会重新核对按钮；按钮名称、位置或窗口身份变了就停。
看图点击前还会核对按钮附近的画面，避免按钮移动后继续点旧位置。

输入前确认焦点，输入后读回实际文字。也补了部分旧式输入框的填写办法；读不全的旧草稿不做追加。
不支持的单个动作会直接说明，不能悄悄升级成复杂任务。
你切换窗口、结束通话、换会话或停止当前操作后，尚未发出的迟到动作会被拦下。
同一句语音的听写结果和稍后到来的工具请求共用一次执行结果，避免重复点击。

## 还没有做到的部分

- 本轮没有给真实微信联系人发消息，没有验收你的真实麦克风和扬声器。
- 没有承诺所有软件都能读到输入框，也没有保证复杂画面或权限更高的软件都能操作。
- 目前不支持在这条快速通道里双击、拖动、右击或长按；会直接说明，不擅自换办法。
- 点击和按键的成功，只说明这一步已经发出；不能据此声称文件已保存、消息已送达。
- 还没有新增“记住工作流并自动重做”。这次先把可复用的逐步执行方法做好。

以后记住常用流程可行：先由你明确开始记录，保存每一步的目标、动作和确认结果，
再让它在同类页面上照做；遇到画面不同先停下来听你纠正。不能只保存鼠标位置。
让熟悉流程重做，比让它自行处理所有新情况更接近可交付目标。
